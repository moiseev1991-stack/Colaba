2. Какие данные собираются

Через форму заявки на сайте собираются только те данные, которые вы указываете сами:

Единственная цель — связаться с вами по вашей заявке и провести бесплатный разбор. Данные не используются для рассылок без вашего согласия и не продаются.

Данные хранятся столько, сколько нужно для обработки заявки и связи с вами. По вашему запросу на dmitry@spinlid-team.ru данные удаляются.
