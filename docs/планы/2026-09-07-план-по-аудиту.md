## Блок P0 — Деньги и продукт (СЕГОДНЯ–ЧТ, 08–10.09)

### P0.1 Пополнить OpenAI-аккаунт 👤

- **Зачем:** HTTP 402 «нет оплаты» — эмбеддинги мертвы → боли строятся только у 42% компаний. Это главный продукт.
- **Шаги:** зайти на platform.openai.com → Billing → пополнить (рекомендую $20–50: расход моделей ~550₽/мес при 100% ok). Проверить, что платёжный метод не истёк (причина 402 могла быть в протухшей карте — тогда поправить карту).
- **Критерий:** в `api_call_log` за последние час вызовы `openai_emb` с ok=true; через сутки embedding-покрытие отзывов растёт (36% → вверх).
- **После вашего пополнения** 🤖: перегенерировать эмбеддинги для отзывов с NULL (задача уже идемпотентна — само подтянется очередью `maps_ai`; проверю и подхлестну).

### P0.2 DaData: ключ или стоп 🔧

- **Зачем:** 403 на ~5 400 вызовов/день — квота/ключ. Жжёт CPU и логи месяцами.
- **Шаги (👤 решение, 🤖 исполнение):**
  1. Проверить кабинет dadata.ru: тариф (free = 10К/сутки) и статус ключа. 403 = либо лимит, либо подписка истекла.
  2. Если продлеваете — обновить ключ в `/opt/colaba/.env` (DADATA_API_KEY/SECRET), `docker compose up -d` backend+workers.
  3. Если нет — 🤖 ставлю «стоп-кран»: временно отключаю постановку `enrich_company_legal` (одна строка-условие по валидности ключа + PR) — минус 5К бессмысленных вызовов/день.
- **Критерий:** ok% dadata > 90% за сутки ИЛИ задача не ставится вообще (0 вызовов).

### P0.3 2GIS: обновить ключ или выключить 🔧

- **Шаги:** 👤 проверить кабинет dev.2gis.com (ключ мог истечь/отозван). Живого ключа нет → 🤖 PR: убрать `2gis` из дефолтных источников и из health как «ok» (сейчас health врёт «ok» при мёртвом ключе — прикрою статусом по last_test).
- **Критерий:** поисков с источником 2gis = 0 попыток; health честный.

### P0.4 SerpAPI: тариф или throttle 🔧

- **Зачем:** 555₽/мес при 40% ok (rate_limited) — больше половины бюджета внешних API в мусор.
- **Варианты (👤 выбрать):** (а) поднять тариф; (б) 🤖 снижаю параллелизм/добавляю backoff на 429 (rate_limit в коде уже есть — добавлю honoring Retry-After); (в) пауза google-источника до решения.
- **Критерий:** ok% serpapi > 85% за неделю, или расходы ≈ 0.

### P0.5 Возобновить парсинг карт 🤖

- **Зачем:** стоит с 25.08 (`yandex_maps: disabled` в конфиге провайдеров БД) — база не свежеет.
- **Шаги:** включить провайдер в `/app/settings/maps-providers` (проверить, кто disabled — конфиг БД или env-флаг), пробный поиск «стоматология Москва», затем по вашему списку ниш×городов (волнами по 5, оркестратор `/opt/orch3000/orch.py` готов).
- **Критерий:** свежие поиски за сегодня есть; `maps_yandex_html`-бэклог 103К не растёт лавиной (дренаж 1.8/с уже идёт сам).

### P0.6 Алерт-мониторинг интеграций 🤖 (главный урок месяца)

- **Зачем:** всё P0 умирало месяц молча. `api_call_log` уже пишет всё — не хватает только «кто-то смотрит».
- **Шаги (PR):** celery-beat задача раз в час: агрегировать ok% по провайдерам за час; при ok% < 80% (или cost-аномалия, или 402/403) → сообщение владельцу в тот же TG-бот (инфраструктура уведомлений уже есть из inbound_leads!). Дубль в админку — плашка «Интеграции: dadata 16%».
- **Критерий:** при выключенном ключе через час приходит TG-алерт; в админке виден статус.

### P0.7 Прокси для Яндекс-отзывов — решение 🔧

- **Зачем:** PR #197 выпилил резидентский прокси; отзывы рискуют напрямую с серверного IP (Яндекс банит серверные IP на /reviews). Пока парсинг стоит — не горит; перед массовым возобновлением (P0.5) — обязательно.
- **Варианты (👤):** (а) вернуть резидентский пул (тот же Geonix или аналог) как `MAPS_PROXY_URL` — 🤖 вернёт код (правка маленькая, вычистил её же обёртку); (б) принять риск: 🤖 включит счётчик капч в мониторинг P0.6 и алерт при росте.
- **Критерий:** после суток парсинга доля CaptchaWall в логах < 5%.
