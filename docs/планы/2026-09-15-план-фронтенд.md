## 0. Как работаем

- **Мелкие PR:** один этап — 2–4 PR. Ветки `fix/…`, `feature/…`, `refactor/…`, Conventional Commits (правила `AGENTS.md`).
- **Перед каждым PR:** `npm run lint`, `npm run type-check` и **обязательно `npm run build`**. CI сейчас гоняет только lint и type-check (`.github/workflows/ci.yml:85-95`), `next build` не запускает — ошибки prerender всплывают уже на проде.
- **Визуальная проверка до и после:** скриншоты 1440px и 375px ключевых страниц в PR.
- **Сборка** — только локально или в GHA, на VPS не собирать (OOM).
- **Координация:** перед стартом отметить задачу в `.hermes/COORDINATION.md`. Партнёр сейчас работает в бэкенде (warmup, maps, ai), пересечений по файлам не ожидается.
