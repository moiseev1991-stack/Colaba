# Биллинг: кредитная тарификация (2026-09)

> Источники правил: [z.ai devpack usage-revision](https://docs.z.ai/devpack/notice/usage-revision)
> (адаптация под РФ/ЮKassa), практики [Lago](https://getlago.com/blog/credit-based-pricing),
> [Metronome](https://metronome.com/blog/why-ai-pricing-is-moving-to-credits),
> [Anthropic usage credits](https://support.claude.com/en/articles/12429409-manage-usage-credits-for-paid-claude-plans).

## Модель: подписка + кредиты

- **Кредит** — внутренняя валюта. Базовая операция: **1 поиск лидов = 10 кредитов**.
- **Тариф** = месячная подписка (30 дней) с пакетом кредитов. Подписочные кредиты
  действуют до конца периода (правило z.ai: квота периода), докупка не сгорает.
- Списание **FIFO**: сначала истекающие ближайшие гранты.
- Бесплатный тариф: приветственные **100 кредитов** при регистрации (10 поисков;
  решение владельца 19.09 — вернуть 100). Грант идемпотентен и работает и для
  обычной регистрации, и для OAuth-входа.
- **CREDITS_ENABLED=False** — бета бесплатна: списания не производятся, ЛК
  показывает баланс и бейдж «Бета». Включаем при запуске продаж.

## Архитектура

```
users ─< credit_buckets (гранты: granted/spent, expires_at; FIFO)
      ─< credit_transactions (append-only ledger, balance_after)
      ─< subscriptions (период 30 дней, auto_renew, cancel_at_period_end)
      ─< payments (ЮKassa: provider_payment_id unique, granted флаг)
```

- **Списание** — в транзакции запроса, ДО запуска тяжёлой задачи
  (`charge_or_402` в 7 точках: карты, сайты, КП ×2, отправка, черновик,
  ЛПР, DM). При провале задачи — `refund_quietly` (поиск карт/сайтов).
- **402** `insufficient_credits` с расшифровкой (нужно/доступно/не хватает)
  → фронт показывает тост с кнопкой «Тарифы».
- **Webhook ЮKassa не доверяет телу**: берёт id, сверяет платёж через API
  (статус + сумма), грант идемпотентен (`granted`). Страховка от потерянного
  webhook — polling `/payments/{id}/status` с success-страницы.
- **expire_subscriptions_daily** (beat 02:40 UTC) закрывает истёкшие подписки;
  остатки подписочных кредитов гаснут сами по `expires_at` бакета.

## API

- `GET /billing/summary` — баланс, подписка, тарифы, цены операций.
- `GET /billing/transactions?page=&page_size=` — история.
- `POST /billing/subscription` — `{auto_renew?, cancel_at_period_end?}`.
- `GET /payments/plans` — тарифы (единый реестр) + `configured`.
- `POST /payments/create` — платёж + запись в БД; `POST /payments/webhook`.

## Запуск продаж (чеклист)

1. Завести магазин ЮKassa, прописать `YOOKASSA_SHOP_ID`/`YOOKASSA_SECRET_KEY`/`YOOKASSA_RETURN_URL` (Coolify + deploy env).
2. Указать webhook URL `https://www.spinlid.ru/api/v1/payments/webhook` в ЛК ЮKassa.
3. `CREDITS_ENABLED=true`.
4. Проверить: оплата тестового платежа → грант в истории, баланс, подписка.
5. Текущим бета-юзерам — админ-грант переходного периода (по решению владельца).
