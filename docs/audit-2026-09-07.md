## 1. Что изменилось за месяц (16 PR, +5958/−1647)

### Модуль razbor (PR #191–206) — главное приобретение

Лид-магнит на базе болей: спарсенные отзывы → боли → КП с персональной ссылкой → лендинг группы боли → заявка/TG-бот (персона «Дмитрий», без бренда SpinLid). 4 лендинга (`/razbor{,/zvonki,/ocheredi,/zakazy}`) на едином шаблоне `RazborTemplate.tsx` + конфиг. Backend: `inbound_leads` (миграция 057), форма с honeypot + rate-limit 5/ч + consent, TG-webhook с deep-link, заявки в админке. Выгрузки для подрядчиков (`build_rassylka_exports.py`, 708 строк): XLSX email/telegram со всеми компаниями с болью и готовым текстом касания.
**Качество: 4.5/5** — без копипаста, SEO/JSON-LD/canonical, fail-closed секрет, секретов в коде нет.

### Pain automation (PR #190–192)

Новые ключи: `chat_no_response`, `order_online_hard`, `order_wait` (D1); расширение матчинга («не связаться», «бронь»). Проверено на прод-лейблах. Плюс merge-safe enrich (не затирает контакты) и чанкинг вставки отзывов (фикс Interface error).

### Инфра-изменения (PR #191, #197–198)

- Анти-зомби: `init: true` + `--max-tasks-per-child` у воркеров (усиление моих фиксов, не откат).
- **PR #197: выпилен резидентский MAPS_PROXY_URL/Geonix** — парсинг Яндекс-отзывов через общий PROXY_LIST или напрямую с серверного IP (риск капчей именно на /reviews/). Причина в коммите не объяснена.
- PR #198: TG Bot API через SOCKS5-цепочку с fallback (грамотно, креды маскируются в логах).

### Целостность августовских фиксов: **7/7 ✅**

Load-guard, batch-timeout 480s, skip_yandex_html, разделение очередей, @fontsource, пагинация истории (#207), rate-limit поиска — никто не откатил.
